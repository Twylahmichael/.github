# Encore Fitness Studio — Website Additions Proposal

**TWYLAH DIGITAL**

**Phase 1:** Dynamic Schedule, WhatsApp Booking & Admin Panel — built onto your live **efn.co.ke** site.

---

efn.co.ke is already live on WordPress with a working shop, membership plans, and a fitness studio page — built by Imarisher. This proposal is **not a rebuild**. It's a companion system that plugs into your existing site to fix the two real pain points:

- The class schedule is hardcoded (a developer has to edit it to change a coach)
- There's no direct WhatsApp booking

Your shop, checkout, and accounts stay exactly as they are.

---

## What's Already Live (Untouched)

- **Shop (WooCommerce)** — homepage, product catalogue, cart, checkout, customer accounts — stays exactly as is, no rebuild.
- **Fitness Studio Page** — hero, about, membership plans, static workout schedule.
- **Rest of the Site** — Home and Contacts pages.

## What We're Adding

- **Homepage Refresh** — Photo marquee of real facility photos + animated stat counters (7 Classes Weekly, 3+ Years Running, 24/7 Online Booking, KES 400 Daily) that always show correct numbers, even if the animation doesn't load.
- **Dynamic, Bookable Class Schedule** — Replaces the static Elementor table. Styled as a timetable board, pulled live from a database your staff update themselves — no developer, no redeploy. Each class card is tappable → opens WhatsApp pre-filled with that exact class, day, and time.
- **WhatsApp-First Booking** — Membership CTAs point straight to WhatsApp instead of the generic signup form, alongside a simple "How Booking Works" 4-step section.
- **Coaches Section** — Photo, name, and specialty for each coach — pulled from the same source as the schedule, so it's always in sync.
- **Community & Events** — Saturday Dance Club, Polar Run Club, and future events — editable from the admin panel.
- **Gallery** — Filterable tabs (Facility / Classes / Coaches / Events) using your real gym photos, no stock imagery.
- **Location & Footer** — embedded map, refreshed footer with socials (IG, TikTok), M-Pesa Till, "Website by Twylah."

## Admin Panel

A role-gated panel (Owner / Staff) that plugs into the WordPress site without touching wp-admin or WooCommerce:

- **Dashboard** — today's & this week's bookings, and a flag for any class still missing a coach.
- **Schedule Manager** — fast inline coach reassignment — built for the weekly reality of the schedule changing.
- **Content Manager** — events, gallery uploads, hero text/stats.
- **Bookings View** — table structure built now, wired up once member accounts exist in Phase 2.
- **Simple Audit Log** — "who changed what, when" for schedule and content edits.

## How It Plugs In

The schedule, coaches, events, and gallery are powered by a small database and admin panel, then embedded directly into your existing Elementor pages — so day-to-day updates happen in the new admin panel, not in WordPress. WooCommerce, checkout, and customer accounts are never touched.

## Design Direction

Warm and premium, not dark mode — ivory backgrounds, nude/sand cards, teal accents from the Encore ring logo, magenta for CTAs and pricing, bold condensed headers. Real facility photography throughout — matched to the visual language already on efn.co.ke.
